# Arquitetura editorial do frontmatter

A estrutura foi separada do conteúdo dos capítulos.

Fluxo do `main.tex`:

1. capa
2. `\frontmatter`
3. folha de rosto
4. ficha catalográfica
5. dedicatória
6. agradecimentos
7. sumário
8. `\mainmatter`
9. Partes
10. capítulos
11. `\backmatter`
12. bibliografia

## Observações

- A capa é estrutural/provisória; a arte definitiva ainda não foi definida.
- A ficha catalográfica é apenas um espaço reservado. Não deve ser tratada como ficha oficial.
- A dedicatória e os agradecimentos contêm marcadores para o texto definitivo.
- A epígrafe foi preparada, mas permanece desativada no `main.tex`.
- A identidade visual e o preâmbulo não foram alterados nesta etapa.
