# Política editorial de fontes

## 1. Fatos históricos específicos
Usar `\footcite{chave}` quando a afirmação depender de uma fonte identificável.

Exemplo:

```latex
Em 1945 foi criada a Organização das Nações Unidas.\footcite{onu1945}
```

## 2. Síntese histórica
Não é necessário colocar uma nota em cada frase de conhecimento histórico geral. A fonte deve ser indicada quando houver uma afirmação específica, dado, data, citação ou informação que o leitor possa querer verificar.

## 3. Memória de Dona Maria
Diferenciar claramente:
- memória oral;
- documento familiar;
- fonte histórica;
- interpretação narrativa.

Memórias pessoais podem ser registradas em nota quando necessário, sem transformá-las em referência bibliográfica acadêmica.

## 4. Fotografias
Usar legenda + fonte. Para material familiar:
`\fonteImagem{Acervo da família}`

Para material externo:
`\fonteImagem{GEAstro/UTFPR, 2016}`

## 5. Bibliografia final
A bibliografia será gerada automaticamente a partir das fontes efetivamente citadas.
